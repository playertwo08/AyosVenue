# Current implementation scope

The supplied Features.pdf remains the reference for AYOS Venue product capabilities. The latest user instruction overrides the initial Java stack: this project is now HTML, CSS and JavaScript only.

AYOS Technology is the primary pickleball court directory. It connects court discovery to the client venue website and booking demonstration. Baseline is a fictional sample affiliation because actual client/affiliate details were not supplied.

Working browser demonstrations: search/price filter, venue/court navigation, multiple slots/courts, totals, sample players, rentals, temporary holds, full/deposit simulation, confirmation, QR passes, one-time check-in and local recovery.

Product capabilities requiring production integrations, operational workflows, notifications, real payments and protected shared records are described, not implemented as real services. Browser storage is editable and isolated from other devices. No real affiliation, payment or live booking claims are made.
